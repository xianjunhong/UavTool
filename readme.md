# UAV-RS Workbench（UavTool）

面向遥感数据生产与无人机航测的一体化桌面工作台。

项目基于 Python、PySide6 与 GDAL/OGR，打通“大幅面 GeoTIFF 导入—多尺度可视化—控制点几何校正—地块 ROI 管理与批量裁剪—小区 Shapefile 汇总—DJI 航线任务生成”流程，可作为遥感模型训练/推理前的数据准备工具和外业采集辅助平台。

> 当前版本聚焦遥感大模型上游的数据工程与航测工具链，不包含模型训练、微调或推理模块。

## 核心亮点

1. **大幅面遥感影像浏览**：构建 4～64 倍共 5 级轻量 Overviews，在控制文件体积的同时按当前视窗动态读取局部影像；支持 NoData 过滤、2%～98% 分位拉伸与 RGB/MS 波段映射。
2. **可解释的控制点配准**：通过最小二乘求解二维仿射变换，输出训练 RMSE、最大误差、留一 RMSE，并使用矩阵秩、行列式与条件数检测退化解。
3. **地块 ROI 样本生产**：支持 Shapefile、GeoJSON、GPKG 跨坐标系加载，多边形自相交修复，以及 GeoTIFF/PNG 批量裁剪与 Alpha 掩膜输出。
4. **小区库汇总**：批量合并多个 Shapefile，保留 `name`、`plot_idx` 和整列编号规则，并自动统一输入坐标系。
5. **无人机航测任务生成**：将影像像素坐标转换为 WGS84 航点，按 DJI WPML 1.0.6 生成包含 `template.kml` 和 `waylines.wpml` 的 KMZ 任务。
6. **工程化交付**：耗时任务通过 QThread 异步执行并反馈进度，支持使用 PyInstaller 打包为 Windows 可执行程序。

## 功能模块

1. 航线绘制与 DJI WPML/KMZ 导出。
2. GeoTIFF 金字塔构建。
3. 控制点仿射几何校正。
4. 任意多边形影像裁剪。
5. 地块库管理与批量样本导出。
6. Shapefile 小区库合并。

## 当前可以做什么

### 1. 航线绘制页

1. 导入 TIF 并自动检查是否包含金字塔（无金字塔时拒绝导入）。
2. 大图浏览：
   - 鼠标滚轮缩放。
   - 左键按住拖动平移。
   - 右键按住也可平移。
3. 航点编辑：
   - 左键点击添加航点。
   - 右键点击航点附近可删除航点。
   - 图上显示编号航点，右侧同步显示经纬度列表。
   - 列表每行有 x 删除按钮，可删除对应航点。
   - 双击列表项可定位到图上对应点。
4. 导出 KMZ：
   - 点击“导出航线”。
   - 先选择无人机型号，再设置系统开放的该机型专用参数、速度、高度和输出路径。
   - M3T 不显示不可独立控制的云台偏航；需要改变水平拍摄方向时，使用“固定航向”和飞机航向角。
   - 云台俯仰和 M300 云台偏航均可按需启用；未勾选的可选角度不会写入 KMZ 动作。
   - 生成包含 wpmz/template.kml 和 wpmz/waylines.wpml 的 .kmz 文件。

### 2. 金字塔构建页

1. 选择 TIF 后自动检测金字塔层级。
2. 若已包含金字塔，直接提示并禁用构建按钮。
3. 若不包含金字塔，可一键构建 overviews。
4. 构建过程异步执行并显示进度条，不阻塞 UI。

### 3. 图像配准页

1. 正常配准：
   - 选择 src 图像和 target 图像。
   - 在左图按顺序打 src 控制点，在右图按同顺序打 target 控制点。
   - 至少需要 3 对点，建议 4 对及以上，且尽量分散分布。
   - 默认勾选“同时导出参数 CSV”；完成后会在结果 TIF 旁生成 `*_params.csv`。
2. 参数复用（适合与正射影像同期、同坐标基准的 DEM）：
   - 点击“选择 src 图像 / 参数 CSV”，直接选择上一次生成的参数文件。
   - 选择需要校正的 DEM 或其他 target GeoTIFF，无需再次寻找控制点。
   - 复用模式不加载 target 预览，因此大幅 DEM 即使尚未构建金字塔也可以直接处理。
   - 点击“应用参数并对齐”输出新的 TIF。
   - 参数保存的是地理坐标层面的校正，因此 target 与原正射影像分辨率或裁切范围不同也可以复用。
   - 程序会校验新 target 的原始坐标系；与参数记录不一致时会拒绝执行。
   - 坐标系一致只是最低条件；新 target 必须确实与参数中记录的原 target 来自同批次、共享同一套原始空间定位，不能把参数套到任意同坐标系影像。
3. 配准和参数复用均异步执行并显示进度条。
4. 配准结果输出为新的 TIF 文件（默认 `*_aligned.tif`），不会修改原 target 文件。
5. 对齐输出会自动构建金字塔，便于后续快速浏览。
6. 正常配准完成后会显示误差与稳定性指标：
   - 训练 RMSE（控制点拟合误差）
   - 最大误差
   - 留一 RMSE（点数 >= 4 时）
   - det(A) 与 cond(A)（用于判断变换是否退化）

### 4. 图像裁剪页

1. 选择待裁剪影像后，在图上左键绘制多边形，右键撤销最后一个点。
2. 支持两种输出模式：
   - 输出新图（默认 *_crop.tif）
   - 覆盖原图
3. 支持自动修复沙漏型（自相交）点序，避免因点序导致裁剪失败。
4. 裁剪输出带 Alpha 掩膜，查看器按透明显示，减少黑边视觉干扰。
5. 裁剪过程异步执行并显示进度；GeoTIFF 输出完成后自动构建金字塔。

### 5. 小区裁剪页

1. 左侧影像交互区 + 右侧小区列表，支持小区绘制与管理。
2. 小区库管理：
   - 添加当前小区（命名）
   - 整列生成小区：用 4 个顶点框选一整列，设置小区数量、名称前缀、编号和 A/B 编号起点后自动切分。
   - A/B 端使用大号彩色徽标显示，编号起点会明确标注，并在整列外侧显示方向箭头。
   - 整列编辑期间会在每个小区中心显示粗体、高对比度名称。
   - 整列生成后立即进入共享网格编辑：拖动外框角点、整条分隔线、分隔线单侧端点或整列内部。
   - 支持重新等分、增加/删除分隔线、反转编号方向、`Ctrl+Z` 撤销和 `Esc` 取消。
   - 编辑已有整列时可重新设置名称前缀、起始编号和编号位数，整列名称及 Shapefile 命名字段同步更新。
   - 整列调整会实时保存到内存，点击一次“完成整列编辑”即可确认。
   - 地图或列表单击只负责选择和高亮，不会自动定位或进入编辑，避免误触。
   - 选择后点击“编辑选中小区”才显示橙色顶点并进入微调；修改自动保存到内存。
   - 支持上一小区/下一小区连续选择；选中小区高亮，其他轮廓变淡并隐藏名称。
   - 拖动顶点或整列控制线时显示局部放大镜。
   - 重命名选中小区
   - 删除小区
   - 保存小区库（Shapefile）
   - 加载小区库（支持 shp/geojson/gpkg）
   - 新版 Shapefile 会保存列 ID、列内位置、编号方向等字段，可在重新加载后恢复整列编辑。
3. 小区显示与应用：
   - 已保存小区在图上显示轮廓与名称。
   - 点击“编辑选中小区”后，将选中小区应用到编辑多边形并自动定位。
4. 批量导出：
   - 选择输出文件夹后按小区名称逐个导出。
   - 默认导出 GeoTIFF。
   - 勾选“裁剪导出为 PNG”后，会同时应用界面右上角的显示旋转角度。
   - PNG 使用多边形 Alpha 掩膜，方向与用户绘制小区时看到的界面保持一致。

### 6. Shap 合并页

1. 一次选择至少两个由“小区裁剪”页生成的 Shapefile。
2. 按选择顺序合并所有有效小区多边形。
3. 保留 `name`（小区编号/名称）、`plot_idx`、列内位置、编号方向和编号前缀，不自动改动可见的小区编号。
4. 自动将各源文件的内部列 ID 映射为全局唯一值，避免不同文件中的 `column_1` 被误合并为同一列。
5. 若输入坐标系不同，自动转换到列表中第一个 Shapefile 的坐标系。
6. 输出为新的 Shapefile，不允许将任一输入文件作为输出路径。
7. 合并过程在后台线程执行，并显示进度和最终小区数量。

### 7. 高度提取页

1. 选择包含 DEM/DSM 小图的目标文件夹。
2. 选择一个基准 TIF；基准文件位于目标文件夹内时会自动跳过，不会作为目标重复计算。
3. 默认使用基准文件 P50（中位高程）作为基准，提取每个目标文件的 P95、P99。
4. 相对高度按“目标百分位高程 - 基准高程”计算，百分位可在界面中修改。
5. 自动过滤 NoData、0 值和 Alpha 掩膜外像元。
6. 结果保存为目标文件夹中的 `height_extraction_results.csv`，同时包含绝对高程和相对高度。
7. 批量计算在后台线程执行，并显示进度、成功数量和失败数量。

## 页面结构

应用使用 QStackedWidget 七页结构，并通过顶部 Tab 栏切换：

1. 航线绘制
2. 金字塔构建
3. 图像配准
4. 图像裁剪
5. 小区裁剪
6. Shap 合并
7. 高度提取

## 技术栈

1. PySide6: 桌面 UI
2. GDAL/OGR: GeoTIFF 读取、坐标写回、金字塔构建与 Shapefile 合并
3. pyproj: 坐标系转换（影像投影 -> WGS84）
4. XML + zipfile: WPML 生成与 KMZ 打包
5. NumPy: 仿射参数求解与配准误差计算

## 目录说明

1. main.py: 程序入口
2. ui/: 页面与图像交互组件
3. logic/: KMZ 导出、金字塔构建、图像配准、图像裁剪、小区库读写、合并与批量导出逻辑
4. utils/: 运行环境与地理工具

## 运行方式
启动命令：

python.exe main.py

## 已知说明

1. 航线绘制页仅支持 RGB 三波段及以上影像。
2. KMZ 导出基于当前航点顺序，按点位附加拍照动作。
3. 无人机型号差异目前主要体现在 WPML 中的机型/载荷枚举参数。
4. 配准时若控制点近共线，矩阵可能退化（det(A) 过小或 cond(A) 过大），系统会拒绝写出并提示重选点。
5. 当仅使用 3 对点时，训练 RMSE 可能接近 0，这是仿射模型精确拟合控制点导致，不代表全图误差为 0。
6. 小区库保存使用影像坐标系，加载时会尝试自动转换到当前影像坐标系。
7. PNG 输出不包含 GeoTIFF 地理参考信息；若需保留地理坐标，请使用 TIF 导出。
8. PNG 裁剪会应用小区裁剪页当前的显示旋转角度；GeoTIFF 裁剪继续按地理坐标输出，两者方向可能不同。
9. Shap 合并保留原编号；若不同源文件存在相同编号，合并结果也会保留这些重复值，不会自动改号。
